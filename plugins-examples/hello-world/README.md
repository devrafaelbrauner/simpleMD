# Hello World (exemplo de plugin do simpleMD)

Copie `manifest.json` e `main.js` para `<sua pasta>/.simplemd/plugins/com.exemplo.hello-world/`,
abra Configurações → Plugins, clique em “Recarregar lista” e ligue “Hello World”. Leia o aviso:
um plugin roda com o mesmo acesso que o simpleMD (não é sandbox).

- Comando “Dizer olá” (paleta de comandos ou `Mod-Shift-H`): mostra um aviso.
- Decoração: toda ocorrência de `hello` (sem diferenciar maiúsculas) ganha fundo de destaque.

Referência completa: `docs/plugins.md`.
